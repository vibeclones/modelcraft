# modelcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [modelcraft](https://github.com/getcadcraft/modelcraft), by CadCraft. The newest version lives at getcadcraft.com/use/modelcraft; this repo keeps older versions open-able so the timeline can be explored in a browser. This repo only mirrors upstream release zips; the code is theirs. Upstream license: Apache-2.0.

- Latest: `/modelcraft/latest/`
- Specific version: `/modelcraft/v<version>/`
- Version list: `/modelcraft/versions.json`

Each version folder is the unmodified contents of upstream's browser build zip from the matching release. A scheduled workflow mirrors new releases.
